DSO AGENCIA SAS — PRIMERA VERSIÓN WEB
=====================================

Contenido
- index.html: página principal
- styles.css: diseño adaptable para escritorio y móvil
- script.js: menú móvil, año automático y validación demostrativa del formulario
- assets/logo-dso.png: logotipo proporcionado por el usuario

Cómo abrir
1. Extrae el ZIP en una carpeta.
2. Abre index.html con Chrome, Edge o Firefox.
3. Para editar, abre los archivos con Visual Studio Code u otro editor.

Importante
- El formulario es solo una demostración: no envía ni guarda datos.
- No hay registro de usuarios ni área para adultos implementados todavía.
- Los textos de instalaciones, políticas y canales de contacto son provisionales.
- Antes de publicar, verifica los datos empresariales y prepara políticas de privacidad, tratamiento de datos y consentimiento aplicables.
- Para conectar un formulario real se necesitará un backend o proveedor de formularios y revisar su política de privacidad.
- Para contenido para adultos, confirma primero que el alojamiento lo permita y aplica controles efectivos de edad, acceso y consentimiento.
- La tipografía usa Google Fonts si hay conexión a internet; el sitio conserva fuentes de respaldo si no hay conexión.
